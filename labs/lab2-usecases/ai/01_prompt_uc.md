# Промпт 01: Генерація Use Case діаграми

Завдання до AI:
На основі файлу `spec.md` (де вказані актори: Клієнт, Кур'єр, Менеджер та їхній абстрактний батько Авторизований користувач) згенеруй код Use Case діаграми у форматі Mermaid.

**Обмеження та критерії:**
1. Використати узагальнення (наслідування) для акторів.
2. Відобразити базові прецеденти для батьківського актора та специфічні для дочірніх.
3. Для головного прецеденту "Оформити замовлення" обов'язково додати зв'язки `<<include>>` (Оплатити замовлення) та `<<extend>>` (Застосувати акцію).
4. Не додавати як акторів саму систему або платіжні шлюзи (вони поза обсягом).
